# Rochester Sports Foundation — Static Sandpiper Build

This version uses plain HTML, CSS, and JavaScript. It does not require Node, npm, React, Vinext, or a build process.

## Preview in VS Code

1. Open this folder in VS Code.
2. Click **Go Live**.
3. Live Server will open `index.html`.

The shared header and footer are loaded from `/includes/`, so preview the site through Live Server rather than opening HTML files directly from Finder.

## Main files

- `index.html` — Homepage
- Each interior page is in its own folder, such as `projects/index.html`
- `includes/header.html` — Shared navigation
- `includes/footer.html` — Shared footer
- `assets/css/style.css` — All styling
- `assets/js/main.js` — Shared includes and mobile navigation
- `assets/images/` — Images
- `assets/docs/` — PDFs

This is an initial prototype. The contact form is not connected, and historical news migration remains in progress.
